## Navegador e aplicação real

Playwright 1.63.0 e Chromium foram executados contra o gateway local, com contextos isolados. Resultado detalhado em [2026-10-18-docker-browser.json](2026-10-18-docker-browser.json).

- 37 verificações passaram, sem erros de página e sem chamadas ao Supabase.
- Páginas públicas em desktop e mobile; proteção de `/painel` para visitante anônimo; sem overflow horizontal nos caminhos examinados.
- Abrigo: painel, cadastro, dinâmica, vagas e equipe.
- Voluntário: painel, cadastro e vagas.
- Administrador: abrigos e gerentes.
- Equipe ativa e desativada; escrita da equipe desativada bloqueada com 403.
- Login bcrypt e logins legados `$wp` oficial com caracteres especiais, phpass e MD5; migração para bcrypt e vínculo ao abrigo.
- Cookies `mv_at`/`mv_rt` HttpOnly, SameSite=Lax, Path=/, Secure=false no HTTP local.
- Renovação da sessão pelo Proxy SSR após remover `mv_at` e logout com bloqueio de novo acesso protegido.
- Troca de senha com rejeição da senha anterior e aceitação da nova.

Todas as contas usadas no navegador eram sintéticas. Elas, seus cadastros e sessões foram removidos após o teste, e o destino voltou a coincidir com o snapshot. Não foram alteradas senhas de contas importadas para possibilitar os testes. O smoke com uma conta real e senha conhecida continua sendo uma etapa do ensaio manual/cutover.

## Verificações de implementação

- Front: 195 testes passaram; lint sem erros, com os três avisos preexistentes; typecheck passou.
- Builds Docker da API, migrator, tools e front passaram. O front gerou as 91 páginas, com Proxy presente.
- API: lint e typecheck passaram.
- As 447 verificações unitárias da API passaram dentro da imagem `tools`, com Redis isolado no database 15.
- As 64 verificações E2E da API passaram dentro do Docker, usando PostgreSQL do ambiente carregado e Redis isolado no database 14. A comparação posterior continuou sem diferenças no banco.
- O teste das ferramentas revelou a necessidade de Node 24 para o Jest carregar módulos ESM. A imagem `tools` foi separada do runtime para satisfazer isso. Os testes unitários também precisam das variáveis obrigatórias de configuração, pois parte das suítes importa o AppModule; não se deve depender de um `.env` local copiado para a imagem.
- Nginx validado com `nginx -t`; front e API rodam como UID 1000; nenhum arquivo `.env` local foi copiado para as imagens de runtime; a URL de build não está no ambiente de runtime do front.
- A revisão estática independente de Docker, roteamento, segredos e ordem de subida não encontrou bloqueadores.

## Limites do ensaio

Este ensaio valida o snapshot de setembro e as imagens locais. Não valida dados gravados no Supabase depois desse snapshot, a infraestrutura Dokploy real, HTTPS de produção, entrega real de e-mails ou senhas reais desconhecidas.

O build apresentou avisos de dependências do npm e avisos já existentes na geração da imagem OpenGraph. Não houve atualização automática de dependências nesta tarefa. O logo referenciado pelo próprio domínio local não fica acessível em `localhost` dentro do builder; isso não impediu a geração das páginas nem os fluxos funcionais examinados.

Para reproduzir a infraestrutura e a carga, seguir [DOCKER-LOCAL.md](../DOCKER-LOCAL.md). Para a migração definitiva, gerar novo dump com as gravações interrompidas e seguir [IMPORT.md](../IMPORT.md).
